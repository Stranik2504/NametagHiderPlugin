# NametagHider

Плагин для скрытия ников игроков и их кратковременного отображения по нажатию ПКМ по игроку. Отображаемый текст настраивается, функцию показа можно отключить.

## Возможности
- Скрывает ники над головами игроков.
- Кратковременный показ ника по ПКМ по игроку.
- Переключаемая функция показа.
- Кастомизация выводимого текста.

## Требования
- Сервер на базе Spigot/Paper.
- Java и Gradle (проект на Gradle).

## Установка
1. Соберите плагин или возьмите готовый `.jar`.
2. Поместите файл в папку 'plugins' вашего сервера.
3. Запустите сервер для генерации 'config.yml' в папке плагина.
4. Настройте плагин в 'config.yml'.
5. Перезапустите сервер.

## Настройка
Основные параметры находятся в 'resources/config.yml' и в сгенерированном 'plugins/NametagHider/config.yml'.

- `enabled`: включает/выключает логику скрытия ников. Пример — `true`.
- `rightClickView`: включает/выключает показ ника по ПКМ. Пример — `true`.
- `nicknameFormat`: формат выводимого текста. Используйте плейсхолдеры, например `{name}` для ника. Пример — `&eНик: {name}`.

Примечание: точные ключи и значения смотрите в вашем 'config.yml'.

## Использование
- По умолчанию ники скрыты.
- Чтобы временно показать ник конкретного игрока, нажмите ПКМ по нему.
- Формат и длительность показа регулируются в 'config.yml'.
- Показ по ПКМ можно полностью отключить (см. `rightClickView`).

## Команды и права
Для использования команд требуется разрешение `nametagHider.commands`

**Команды:**
- `/nametagHider reload` — перезагрузка конфигурации плагина.
- `/nametagHider set-rc [true/false]` — включение/выключение функции показа ника по ПКМ.
- `/nametagHider enabled` — переключение логики скрытия ников.
- `/nametagHider info` — информация о состоянии плагина.

## Сборка из исходников (Windows)
1. Откройте проект в IntelliJ IDEA.
2. Выполните в терминале:
    - `.\gradlew.bat clean build`
3. Готовый `.jar` ищите в 'build/libs'.
